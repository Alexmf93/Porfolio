# Mi Portafolio - Alejandro Moya Fernández

Bienvenido a mi portafolio web personal. Este proyecto es una presentación interactiva de mis habilidades, proyectos y experiencia como desarrollador web full-stack.

## 🎯 Descripción del Proyecto

Portafolio moderno y responsivo desarrollado con HTML, CSS y JavaScript. Cuenta con un diseño futurista con animaciones interactivas, navegación fluida y un fondo estelar animado.

## ✨ Características

- **Diseño Responsivo**: Adaptable a cualquier dispositivo (desktop, tablet, móvil)
- **Fondo Estelar Animado**: Canvas interactivo con efecto de espacio 3D
- **Navegación Hamburguesa**: Menú móvil inteligente y funcional
- **Animaciones CSS**: Transiciones suaves y efectos visuales modernos
- **Tema Futurista**: Paleta de colores neon con gradientes vibrantes
- **Scroll Suave**: Navegación fluida entre secciones

## 🎨 Personalización

### Cambiar Colores
Edita las variables CSS en `css/estilos.css`:
```css
:root {
    --color-primary: #00d4ff;      /* Color principal (cyan) */
    --color-secundary: #7b2ff7;    /* Color secundario (púrpura) */
    --color-accent: #ff00d4;       /* Color de acento (magenta) */
    --color-dark: #0a0e27;         /* Fondo oscuro */
    --color-light: #f0f4ff;        /* Texto claro */
}
```

### Editar Contenido
Modifica el contenido directamente en `index.html` en las secciones correspondientes.

### Ajustar Animaciones
En `js/script.js` puedes modificar:
- Número de estrellas (`NUM_STARS`)
- Velocidad de las estrellas (`SPEED`)
- Comportamiento del menú hamburguesa

## 📱 Accesibilidad
